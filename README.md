## ✨ Особенности

- 📍 **Геолокация пользователей** - автоматическое определение местоположения посетителей
- 📱 **Адаптивный дизайн** - работает на всех устройствах (ПК, планшеты, мобильные)
- 📊 **Админ-панель** - просмотр статистики и данных заявок
- 🚗 **Каталог автомобилей** - отображение машин с детальной информацией
- 📝 **Форма обратной связи** - отправка заявок на интересующие автомобили
- 🔒 **Защита админ-панели** - парольная защита для доступа к данным

## 📦 Установка

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- ngrok

### Шаги установки

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/username/autoshop.git
   cd autoshop
   ```

2. **Создайте виртуальное окружение** (рекомендуется)
   ```bash
   python -m venv venv
   # Для Windows
   venv\Scripts\activate
   # Для Linux/Mac
   source venv/bin/activate
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение**
   ```bash
   # Для Linux/Mac
   chmod +x launch.sh
   ./launch.sh
   # Для Windows
   python main.py
   ngrok http 5000
   
   ```

5. **Откройте приложение в браузере**
   - Главная страница: http://localhost:5000
   - Админ-панель: http://localhost:5000/admin

## 🚀 Использование

### Для пользователей

1. Откройте главную страницу
2. Нажмите кнопку "Разрешить геолокацию" для определения вашего местоположения
3. Пролистайте каталог автомобилей
4. Заполните форму контактов для связи с менеджером
5. Ваша заявка будет отправлена и сохранена в базу данных

### Для администраторов

1. Перейдите на страницу `/admin`
2. Введите пароль для входа (по умолчанию: `admin`)
3. Просмотрите статистику:
   - Общее количество заявок
   - Количество геолокаций
4. Переключитесь между вкладками:
   - **Заявки контактов** - все заявки от пользователей
   - **Геолокации** - координаты пользователей с ссылками на карты

### Персонализация

**Изменение пароля администратора:**
Откройте файл [`static/js/admin.js`](static/js/admin.js:19) и измените значение переменной `ADMIN_PASSWORD`:

```javascript
const ADMIN_PASSWORD = 'ваш_новый_пароль';
```

## 🔌 API endpoints

### `GET /`
Главная страница приложения.

### `GET /admin`
Админ-панель для управления данными.

### `POST /api/contact`
Отправка заявки контакта.

**Тело запроса:**
```json
{
  "name": "Иван Иванов",
  "phone": "+380671234567",
  "email": "ivan@example.com",
  "car": "BMW X5",
  "message": "Интересует автомобиль",
  "timestamp": "2024-01-01T12:00:00.000Z"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Заявка успешно отправлена!",
  "contact_id": 1
}
```

### `GET /api/locations`
Получение всех геолокаций пользователей.

**Ответ:**
```json
{
  "locations": [
    {
      "lat": 50.45,
      "lng": 30.52,
      "locationUrl": "https://www.google.com/maps?q=50.45,30.52",
      "timestamp": "2024-01-01T12:00:00.000Z",
      "user_agent": "Mozilla/5.0..."
    }
  ]
}
```

### `POST /api/location`
Сохранение геолокации пользователя.

**Тело запроса:**
```json
{
  "lat": 50.45,
  "lng": 30.52,
  "locationUrl": "https://www.google.com/maps?q=50.45,30.52",
  "timestamp": "2024-01-01T12:00:00.000Z"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Геолокация сохранена",
  "location_id": 1
}
```

### `GET /api/contacts`
Получение всех заявок контактов.

**Ответ:**
```json
{
  "contacts": [
    {
      "name": "Иван Иванов",
      "phone": "+380671234567",
      "email": "ivan@example.com",
      "car": "BMW X5",
      "message": "Интересует автомобиль",
      "timestamp": "2024-01-01T12:00:00.000Z"
    }
  ]
}
```

### `GET /api/stats`
Получение общей статистики.

**Ответ:**
```json
{
  "total_contacts": 10,
  "total_locations": 25
}
```

## 🔒 Безопасность

### Важно

1. **Пароль по умолчанию**: `admin`
   - **Рекомендуется изменить пароль** после первой установки
   - Пароль хранится в открытом виде в файле [`admin.js`](static/js/admin.js:19)

2. **Данные пользователей**: Заявки и геолокации сохраняются в JSON-файлы
   - `contacts.json` - заявки контактов
   - `locations.json` - геолокации

3. **Рекомендации по безопасности**:
   - Используйте надежный пароль для админ-панели
   - Не публикуйте файлы `contacts.json` и `locations.json` в открытом доступе
   - Рассмотрите возможность добавления HTTPS для продакшена
